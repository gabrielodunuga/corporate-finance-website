# WeFinance Website

A responsive finance and financial services landing page created by **Gabriel Odunuga**, Frontend Engineer and IT Support.
![Website image](image.png)

The single-page website presents WeFinance as a modern corporate financial solutions company. It includes a hero section, company overview, business statistics, services, key features, latest news, contact call-to-action, responsive navigation, WhatsApp chat, and a scroll-to-top button.

## How to Use

1. Download or clone this project.
2. Open the project folder in VS Code or another code editor.
3. Open `Home.html` directly in a web browser.
4. Use the navigation links to move between sections.
5. Select **Chat with us** to start a WhatsApp conversation.
6. Scroll down to reveal the scroll-to-top button.

No build tools, server, or package installation are required for the current version.

## Customization

- Update the page content in `Home.html`.
- Change colors, spacing, typography, and responsive behavior in `Style.css`.
- Update navigation and button behavior in `Script.js`.
- Add local images to `Assets/` and replace the remote image URLs in `Style.css` if local hosting is preferred.
- Replace placeholder company information, news copy, and contact email before publishing.
